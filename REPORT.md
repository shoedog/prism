## Readings taken conservatively (nobody to ask)
- Arrays, function-declarator and attributed declarators are ineligible (design E1 unwraps arrays; array decay is address-taking, so I refuse).
- Parameters are not classified as plain writes for U (only declarator and assignment targets), so a parameter's signature line never becomes write-only.
- E4 refuses D for any non-pointer declarator whose name has any member or subscript access in the owner (the design says defs rooted at x with `.`/subscript first hop; reads included here is the over-approximation).
- Candidates must resolve to the same declaration as the window (design requires only W's target).
- G2 is checked textually over the owner's lines (and by node kind) and also refuses `_Pragma`; `#pragma` other than `omp`/`acc` is allowed.
- GNU nested functions, K&R parameter declarations: owner off / name ineligible.
- Builtin varargs (`va_start`, `va_end`, `va_copy`, `va_arg`, `__builtin_va_*`) arguments count as escaped.
- A GCC `__attribute__((cleanup(f)))` local is not special-cased (no pair concerns: the cleanup call reads at scope exit where prism has no use).
- `PRISM_C_PRUNE_TRACE` is a measurement aid; it is not a stable interface.
- The pre-merge mutgate lanes (`mutants/*.json`) were not authored or run in this slice (static review of the rule set is covered by the spot-check above).
