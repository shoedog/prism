**REFINED REVIEW**

1. **BLOCKER — `(file,start_line)` is not a valid unique function identity.** The spec asserts distinct functions have distinct start lines, but current code and tests explicitly handle minified same-line functions. Using `(file,start_line)` will overwrite `function a(){...}function b(){...}` on line 1. Use `(file,start_byte)` or `(file,start_line,start_byte)` and thread it through `FunctionId`/cache/nav, or define a deterministic same-line ordinal. Checked: [spec:50](/Users/wesleyjinks/code/slicing/docs/superpowers/specs/2026-06-13-prism-s2-node-identity-design.md:50), [trace:91](/Users/wesleyjinks/code/slicing/src/cpg/trace.rs:91), [test:476](/Users/wesleyjinks/code/slicing/src/cpg/tests.rs:476).

2. **BLOCKER — same-line statement retention lacks CFG edge semantics.** The spec says same-line statements are kept in `(file,line) -> Vec`, but CFG edges are still `{file, from_line, to_line}`. It must specify whether Step 8 wires all-to-all, first-to-first, byte-nearest, or per-function buckets, and update singular consumers such as `statement_at`/`cfg_reachable_lines`. Checked: [spec:84](/Users/wesleyjinks/code/slicing/docs/superpowers/specs/2026-06-13-prism-s2-node-identity-design.md:84), [cfg:17](/Users/wesleyjinks/code/slicing/src/cfg.rs:17), [build:435](/Users/wesleyjinks/code/slicing/src/cpg/build.rs:435).

3. **BLOCKER — parameter marker is undefined.** §6 says “add a parameter marker,” but the schema has no `is_parameter`/kind field and `VarAccess` is only `Def/Use`. Define the field, serde default, equality/Ord behavior, and how it replaces or augments `line == function_start` in `is_parameter_binding`. Checked: [spec:143](/Users/wesleyjinks/code/slicing/docs/superpowers/specs/2026-06-13-prism-s2-node-identity-design.md:143), [types:61](/Users/wesleyjinks/code/slicing/src/cpg/types.rs:61), [trace:188](/Users/wesleyjinks/code/slicing/src/cpg/trace.rs:188).
