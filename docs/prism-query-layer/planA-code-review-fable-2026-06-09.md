**BLOCKER**

1. `src/reasoning/shape.rs:20-22`, `:60-63` — Sink reachability is resolved at line granularity: a sink is `Reached` if *any* variable node on its line is in `trace.frontier`. For `sink(clean); other = tainted`, the tainted use on the same line makes the clean sink report `Reached`, and `witness_graph` then builds a witness chain to the wrong node — the layer's core evidence contract produces false positives. **Fix:** resolve sinks to specific `NodeIndex`/`SymbolRef` nodes (or emit per-variable sink results) instead of "any node on the line."

**MAJOR**

2. `src/cpg/trace.rs:36-67` with `src/cpg/cfg_queries.rs:105-108`, `src/ast.rs:2217-2224` — Silent frontier collapse when a seed has no CFG statement node. Both reviewers found the same root cause from different angles: `statements_in_function` indexes only body statements, so a parameter-definition seed (Codex's concrete case — `DataFlowGraph` registers params as defs on the function-start line, `src/data_flow.rs:204-227`) gets an empty `cfg_set`, and `cfg_valid` then rejects every body use/sink. Claude generalizes it: any `statement_at` miss (continuation-line seed, unrecognized construct, a file whose language lacks CFG extraction in a mixed-language repo) degenerates the trace to "nothing flows," and `Trace` has no warnings field so the degradation is unreportable even though `ReasoningWarning` exists one layer up. **Fix:** on `statement_at` miss, fall back to pure-taint for that seed (mirroring the no-CFG path); treat function-start parameter defs as reaching the body entry; and add a degraded/warnings field to `Trace` so A7 can surface it.

3. `src/cpg/trace.rs:24-28`, `:38-39`, `:53-78` — Multi-source traces cannot attribute per source. `enqueued`/`frontier`/`parents` are global across all seeds, so when two roots both reach the same sink node, the second root's `enqueued.insert` fails and no parent/root is recorded for it — losing all but the first witness, with the winner determined by undocumented input-slice order. This breaks the documented multi-source sanitizer union and the per-source attribution that `ReasoningReason::TaintedBy { source, .. }` will require the moment A7 populates it. Both reviewers agree on cause and fix. **Fix:** key `parents` by `(root, node)` (or track reached roots per node), or run per-seed traces before A7 consumes `Trace`.

4. `src/navigation/types.rs` (`SinkResult.graph_node`) with `src/mcp/tools.rs:196-205`, `src/mcp/output.rs:166-173` — `graph_node: Option<usize>` is a raw index with no specified binding, and nothing keeps it valid. Two facets of one defect: Codex shows the concrete bug — `clip_graph` and byte-budget truncation clip `graph.nodes` but never repair `per_sink[*].graph_node`, leaving serialized indices pointing past the clipped graph; Claude shows the design gap — nothing ties the index to `Evidence.graph`, whose doc says it exists only for ego/repo-map queries, so a future query carrying both an ego graph and a reasoning summary points `graph_node` into the wrong node list, and once serialized it's wire format. **Fix:** set `graph_node = None` for clipped indices in both truncation paths, and before A7 populates it either embed the witness `GraphPayload` inside `ReasoningSummary` or document and enforce that a reasoning-bearing `Evidence.graph` *is* the witness graph.

5. `src/reasoning/shape.rs:33-39` — Boundary classification keys on line equality (`*boundary_line != line`), so a same-line entry+sink (`def g(p): sink(p)`, a legal Python one-liner) makes the exclusion fire and a sink that taint demonstrably flows into reports `NotReached`. The exclusion exists only to keep the param-def line itself non-boundary (pinned by `test_reachability_tri_state`), but it encodes node identity as line arithmetic. **Fix:** compare the queried node's `NodeIndex` against `boundary.to` node identity, not line numbers.

**MINOR**

6. `src/cpg/trace.rs:81-86` — `node_file_fn` returns an empty-string sentinel for non-Variable nodes, which never equals `src_fn`, so a non-Variable DFG neighbor becomes a `BoundaryEdge` with empty identity instead of being skipped. `reachability_at` filters the sink side (`!sf.1.is_empty()`) but nothing filters the boundary side, so spurious `BoundaryExited` classifications can leak. **Fix:** skip non-Variable neighbors in `taint_neighbors`, or return `Option` from `node_file_fn`.

7. `src/cpg/trace.rs:96-127` — `AssignmentPropagation` is line-granular: any Use propagates to every Def on its line, so `a = b; c = d` makes `b` taint `c`. This repo already paid for line granularity once (PR #74's per-call byte-range scoping); this re-creates the same debt at a new seam. Acceptable for v1. **Fix:** record it in the A2/A3 follow-up tracking with a statement/byte-range scoping plan.

8. `src/algorithms/taint.rs:10656-10660` vs `cleansed_categories_for_source` — the `Go|Python|JS-TS` language gate is duplicated from `apply_cleansers`, and "honest-empty" means no test fails when the two sites drift — the adapter just silently under-reports. **Fix:** extract a shared `sanitizer_supported(language)` predicate (natural home: `src/sanitizers/`, where the tracked A2 relocation is already headed).

9. `src/cpg/trace.rs:32-34` — The doc comment overclaims: `cfg_valid` checks each node's reachability *from the seed*, not from its BFS parent, so a parent→child hop can run backwards in control flow. "Reachable via an all-CFG-valid intraprocedural path" will be read as path-consistency, and the witness graph then presents a chain that isn't a CFG-consistent path. **Fix:** reword to "every frontier node is CFG-reachable from the seed," leaving `path_proven` as the honesty valve.

10. `src/reasoning/shape.rs:51-66` — `witness_graph` returns a silently empty payload when the sink isn't reached; correct use requires calling `reachability_at` first, but nothing in the types encodes that ordering. **Fix:** return `Option<GraphPayload>` so the coupling is compiler-checked.
