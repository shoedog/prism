Merged review — Tier 2 Plan A substrate (A3 taint_trace / A4 cleansing adapter / A7 scaffold). Both lenses returned full reviews; their top findings overlap on the same two defects in boundary classification and same-line propagation, merged below.

**1. BLOCKER — `src/reasoning/shape.rs:53-59` (`reachability_for_node`): boundary classification is wrong in both directions.** Both reviewers found the same predicate broken, from opposite sides. Codex: any boundary edge is widened to the whole callee function, so a sink node for `clean` inside `g` returns `BoundaryExited` merely because it shares a function with the boundary target — a false positive. Claude: the `b.to != sink` clause excludes the one node taint literally reaches — when the queried sink IS the boundary target (the callee's parameter def), it returns `NotReached` while every sibling returns `BoundaryExited` — inverted semantics, unpinned by any test (`test_boundary_classification_uses_node_identity` queries `p`'s Use, never its Def). No disagreement on diagnosis; on the fix for siblings, Codex is right and stricter — Claude's "keep the same-function check for siblings" preserves exactly the false positive Codex traced. Fix: `b.to == sink` short-circuits to `BoundaryExited` (Claude's case), and siblings classify as `BoundaryExited` only via a proven intraprocedural data-flow path from `b.to` to the sink, otherwise `NotReached` (Codex's case). Add tests for both the boundary-target-def query and the clean-sibling query.

**2. MAJOR — `src/cpg/trace.rs:112-124` (`taint_neighbors`): same-line `AssignmentPropagation` is keyed on `(file, line)` only.** Every Use propagates to every Def on the line, across statements and across functions. Concretely: semicolon-joined statements leak within a function (`sink(clean); other = tainted`), and minified JS/TS — supported languages, one line per file — degenerates to "everything taints everything," producing spurious `BoundaryEdge`s that finding #1's classifier then converts into false `BoundaryExited`s. Fix: at minimum filter same-line defs by file **and** function (Codex's floor); ideally scope by statement/byte range, the approach this repo already used for the same defect class in PR #74 (Claude). Add a same-line multi-function regression test.

**3. MAJOR — `src/mcp/output.rs:166-173` with `src/navigation/types.rs:143-148`: graph truncation leaves `reasoning.per_sink[*].graph_node` dangling.** The MCP shaper clips `graph.nodes` but never touches the reasoning summary, so a serialized `graph_node: 1` can point past the emitted graph. Fix: clear or remap `graph_node` during clipping, and add a test for clipped reasoning witness output. (Codex-only finding.)

**4. MAJOR — `src/cpg/trace.rs` (`Trace`): `frontier` is redundant public state.** It must equal the union of `frontier_by_root` values, but all six fields are `pub` and the invariant lives only in two adjacent inserts in the BFS. Consumers already split across the seam (`reachability_*` reads `frontier`; `witness_graph_for_node` reads the per-root maps), so the first Plan B post-filter that mutates one map but not the other yields "`Reached` with no witness" — the exact dead-end-witness bug class A3 was built to eliminate. Fix: make `frontier` a derived accessor (or private fields + methods); this also stops leaking raw petgraph `NodeIndex` through `prism::cpg`. (Claude-only.)

**5. MAJOR — `src/reasoning/shape.rs` (`witness_graph_for_node`): unbounded parent walk-back.** `while let Some((p, _)) = parents_by_root.get(...)` relies on a non-local invariant (parents form a tree because trace.rs inserts only on first enqueue). The doc comment all but invites upgrading "DataFlow beats same-line" to parent-slot re-assignment, which would create cycles and turn this into a production infinite loop — while the test suite's own walk-back carries a `g < 1000` guard. Fix: bound the loop here, and/or `debug_assert` the tree invariant where it's produced in `taint_trace`. (Claude-only.)

**6. MINOR — `src/cpg/trace.rs`: "no CFG pruning" is double-encoded.** `cfg_scope_for_seed` returns `Some(BTreeSet::new())` when there's no CFG — an empty set whose literal meaning is "prune everything," safe only because `has_cfg` is checked first; dropping the seemingly redundant `has_cfg` parameter silently flips behavior. Fix: encode the tri-state once, e.g. `enum CfgScope { NoCfg, Degraded, Lines(set) }`.

**7. MINOR — `src/navigation/types.rs`: Tier-2 vocabulary lives in Tier-1's serialized-contract module.** `ReasoningReason`, `ReasoningWarning`, `Reachability`, `SinkResult`, `ReasoningSummary` sit in navigation while `reasoning/seeds.rs` imports from it — the dependency arrow points opposite to the data arrow. Byte-compatibility only forces the `Evidence.reasoning` field there, not the definitions; relocating after external consumers serialize these shapes is a breaking change. Fix: define them under `reasoning/` and have navigation reference them.

**8. MINOR — `Evidence` construction: ten call sites hand-write `reasoning: None`.** The A7 scaffold guarantees at least one more additive field in Plan B, repeating this whole-codebase churn each time. Fix: add `Evidence::new(query)` or `Default` + struct-update syntax now, while the sites are fresh.

**9. MINOR — lossy fidelity across the trace→Evidence seam.** `Trace.warnings` is `Vec<String>` against structured `ReasoningWarning`; `Trace.degraded` is one global bool though degradation is per-seed (one unresolved seed poisons a multi-seed response with no attribution); A4's `cleansed_categories_for_source` returns `Vec<String>` and `sanitizer_category_str` — the crate's first `SanitizerCategory` stringifier — lands in taint.rs. Fix: return typed values (`Vec<SanitizerCategory>`, per-seed degradation), stringify at the shape boundary, and move the stringifier with the already-tracked A2 relocation.

**10. MINOR — `SinkResult` carries no root/source attribution.** `witness_graph_for_node` picks the first root in `BTreeMap` order that reaches the sink — deterministic but semantically arbitrary under multiple seeds; "which source taints this sink" is unanswerable from the output. The per-root data already exists in `Trace`. Fix: plumb `root` into `SinkResult` and witness selection before the shape freezes externally.

Positives worth keeping: the taint.rs layering inversion is explicitly marked TEMPORARY with a tracked relocation, `sanitizer_supported` centralizes language gating, `Evidence.reasoning` is genuinely additive with an omission test, and NodeIndex→`Location` conversion is correctly confined to the shape boundary.

**Verdict: do not merge until the BLOCKER (#1) and the two taint-correctness MAJORs (#2, #3) are fixed; harden the Trace invariants (#4, #5) before Plan B builds on them.**
