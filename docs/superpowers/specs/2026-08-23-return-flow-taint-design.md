**Date:** 2026-08-23. **Base:** main @ 15cb62c. **Roadmap:** row 2 — P14's declared non-goal, the largest remaining reasoning-layer gap. **Reviews:** sol ∥ Ox, declared cap 3; v2 folded sol r1 (3W+4S); v3 folds sol r2 (FIX: 4 WRONG + 4 SMELL): exact-call-RHS shortcut suppression (the same-line AssignmentPropagation shortcut already reaches x=f(user) directly, defeating both the canonical positive and the sanitizer verdict); a span-bound return-expression INPUT relation (Use→ReturnValue) so `return g(user)` connects; an intentional call-stats schema delta for the counters; CpgEdge vs Relation split; ast.rs in scope; fail-closed outcomes for named/forwarded returns; left_flow in the byte census. Round 3 (cap): FIX residual-bounded — v4 folds it (replacement-path-certified suppression; semantic-only ReturnInput; explicit ReturnFlowMode; single transition definition); closure = one scoped confirm (disclosed extension). **v5 folds the kimi-k3 parallel review (of v2; its W1 counter/byte contradiction was already resolved in v3): W2 — Tier-2 verdict changes are INTENDED (see gates); W3 — one singleton-Exact predicate for build and trace; S5-S7 — ascent budget/insertion, synthetic identity key, cache-index/MCP naming.** **Size:** M. **Files:** cpg/{build,trace,types}.rs, **ast.rs (new fenced return API + ReturnInfo extension — r2-S6)**, data_flow.rs (read-only reuse), reasoning/, algorithms/taint.rs, main.rs — **disjoint from the resolution-ladder lanes (R1(b)/#16/#4b), so implementation can run in parallel with that spine.**

## 1. Problem

`x = f(user)`: taint entering `f` via Step-5b arg→param edges dies at `f`'s boundary — nothing connects `f`'s return values back to `x`. `taint_reaches`, Tier-1 `taint`, and trace-based descent all stop. Sinks fed by returned-tainted values are invisible.

## 2. Design

### 2.1 Edge construction (CPG layer, NOT raw DFG)
A new distinct relation, `Relation::ReturnFlow`, added at CPG build time (cpg/build.rs) — the raw `DataFlowGraph` FlowEdge set is UNTOUCHED — but per r1-S4, unified-graph consumers (full_flow's nodes_at enumeration, `dfg_forward_reachable`) can still see new nodes/edges, so byte-compatibility is PROVEN per consumer by gate 2, never claimed by construction. For each `CallSite` whose call expression is the RHS of an assignment/short-var-decl (the lvalue span on the call's line; multi-line call identity per #171 rules):

- **Callee gating (P14 doctrine, kimi-W3 — ONE predicate for build AND trace):** `singleton_exact(outcome) := outcome.resolved.len() == 1 && outcome.resolved[0].confidence == Exact`. Anything else — NameOnly, zero-target, multi-Exact, or MIXED `[Exact+NameOnly]` (representable: per-item confidence, resolution.rs:148-152) — ⇒ NO edge + `return_flow_skipped_{nameonly,multi,mixed}` telemetry (fail-closed; the mixed fixture's verdict is SKIP). The identical predicate gates the trace ascent hop — never the descent's looser any-matching-Exact acceptance.
- **Source endpoints (r1-W1/W2):** returns are enumerated by a NEW span-bearing, **nested-function-fenced** return API (the existing `return_statements` scans the enclosing byte range without a fence, ast.rs:5191-5205 — an uncalled nested closure's `return tainted` must NOT feed the outer caller; the fenced walker at ast.rs:5291-5297 is the pattern). A returned traced variable/path contributes its Use-kind `VarLocation`. A literal/call-expression return contributes a **distinct, NON-SEEDABLE return-value node kind** (a new `CpgNode` variant, never selected by `reasoning/seeds.rs` location/variable seed resolution — r1-W1: a source seed on `return 0`'s line must not select the synthetic endpoint; pinned by that exact negative). **Return-expression INPUT relation (r2-W3, r3-W2): span-bound edges from every SEMANTIC value/receiver Use occurrence INSIDE the fenced return expression → that return's ReturnValue node — callee names and keyword-argument LABELS are excluded (Python `return f(s=other)`: the label `s` is not a Use; both negatives pinned). A ReturnValue node is created for EVERY non-simple return expression (r3-W1: `return user + "x"` gets a ReturnValue with ReturnInput from `user`), so no modeled return is endpoint-less**, so `return identity(user)` and `return html.escape(user)` connect (`user` Use → ReturnValue → caller LHS); when the return expression is a sanitizer call, the sanitizer classification cuts/marks THIS ReturnInput transform — the SINGLE authoritative transition definition (r3-S4). **Storage split (r2-S5): serialized edges are `CpgEdge::ReturnFlow` + `CpgEdge::ReturnInput`; trace witnesses are `Relation::ReturnFlow`/`Relation::ReturnInput` — conversion and traversal filters specified so no existing CpgEdge::DataFlow filter admits them.**
- **Target endpoint:** the caller's LHS Def occurrence. Slice 1 is whole-value: LHS must be a SIMPLE path (bare identifier); destructuring/multi-value returns (Go `a, b := f()`) map positionally ONLY when every LHS is simple, the callee's return arity matches syntactically, AND **both sides carry span-bound identity (r1-S6): the LHS list is AST-parent-bound to the specific assignment node and return expressions carry child-slot spans (the current `ReturnInfo` line/text/kind shape, ast.rs:79-90, is insufficient — extend it); fixtures: same-line double assignment, nested commas/calls in returns, **named bare returns and forwarded multi-value calls = fail-closed SKIP with counters (r2-S7: named-result binding and forwarded slots are NOT modeled in slice 1)**; anything else ⇒ skip + counter (field-sensitive and tuple-partial flow deferred — the Path-C/per-arg-DFG precedent).

### 2.2 Consumers
- **trace.rs:** a `ReturnFlow` ascent hop, plus **exact-call-RHS shortcut suppression (r2-W1/W2): when the flag is ON and an assignment's RHS is an exactly-modeled call (singleton-Exact with ReturnFlow edges present), the same-line `Use → LHS Def` AssignmentPropagation shortcut for THAT assignment is suppressed in trace AND reachability — flow must route through the callee, making callee sanitization decidable. **Suppression requires a replacement-path CERTIFICATE (r3-W1): (i) TOTAL callee-return coverage — every return statement of the callee is modeled (any skipped return — bare/named/forwarded — voids suppression for all its callers' assignments); (ii) every traced Use in the assignment's RHS binds into the modeled path (a nested-call Use like `x=outer(inner(user))` where `user` does not bind to `outer`'s params retains the shortcut — Step-5b binds whole-argument text, so nested Uses are unbound). No certificate ⇒ shortcut retained; certificate state is a per-assignment build-time fact with its own counter** (`safe = f(user)` with `f` sanitizing ⇒ `Sanitized`, never shortcut-`Reached`). NameOnly/unresolved/multi-Exact call RHSs keep today's conservative shortcut. Flag OFF ⇒ no suppression anywhere (byte-compat).** **Gate defined exactly (r1-S5): the call site's resolution outcome has `resolved.len() == 1 && confidence == Exact`** — not "any matching Exact candidate" (the descent's looser acceptance at trace.rs:608-643 is NOT inherited); NameOnly, multi-Exact, and mixed-confidence outcomes are all fixtures. Same recursive/self-call boundary treatment (trace.rs:381 doctrine extended to the return direction; a return edge landing back into the same function's frame terminates the hop), plus **mutual-recursion/two-callsite ascent cycles bounded and pinned (r1-S7)**. **Impl constraints (kimi-S5): the ascent hop consumes the same `MAX_TAINT_DESCENT_DEPTH` budget with `depths` accrual specified in the PR; ReturnFlow neighbors are handled BEFORE the cross-function boundary branch (a naive `taint_neighbors` insertion dies in `descend_target`'s rel!=DataFlow arm and would surface as boundary warnings, trace.rs:384-414). Synthetic-node identity (kimi-S6): keyed on (file, function, return-stmt span, child-slot index) — CpgNode PartialEq ignores spans, and Go `return 0, nil` mints two same-line synthetics.**
- **Sanitizer transition (r1-W3, r3-S4 — single authoritative definition):** `sanitizer_walk` proves only assignment-RHS sanitizer calls (sanitizer_walk.rs:163-203) — `return html.escape(user)` would never become `Sanitized`. The return-expression sanitizer transition is defined ONCE, in §2.1, on the **ReturnInput transform** (a fenced return whose expression is a sanitizer call cuts/marks its ReturnInput edges for the sanitizer's categories); the outgoing ReturnFlow hop carries no sanitizer semantics of its own. Bypass re-walk covers this transition under the identical `ReturnFlowMode` (the P14 bypass-proven doctrine).
- **`taint_reaches` (Tier-2, kimi-W2):** Mode=On by default — **its Reachability verdicts CHANGE by design** (a previously `NotReached`/`BoundaryExited` sink becoming `Reached` through a modeled return IS the feature); the Evidence SCHEMA stays additive-optional, verdict values do not claim stability. The MCP `taint_reaches` surface inherits identically (kimi-S7).
- **Mode seam (r3-S3): one explicit `ReturnFlowMode` threaded through trace/reachability — Tier-2 `taint_reaches` = On, Tier-1 `taint` = from `TaintConfig`, every other consumer = Off; the bypass/exclusion re-walk runs under the IDENTICAL mode as its primary walk.** **Tier-1 `taint`:** consumes `ReturnFlow` behind the `TaintConfig` flag + `--taint-return-flow` CLI flag, DEFAULT OFF in slice 1 so `--format review` output stays byte-identical; flipping the default is a separate follow-up decision with its own same-base control.

### 2.3 Cache
CPG serialized content changes (new relation edges) ⇒ CPG cache +1 at integration (after the resolution spine's transitions; single bump); nav sidecar unaffected (navigation call edges unchanged).

## 3. Acceptance gates
1. Red-first fixtures per language (Go, Python, JS, TS first; C/Rust follow-up): **positives must be RED-verifiable (r2-W1): a callee-INTERNAL source (`f(){ s:=read(); return s }` → `x=f(); sink(x)`) asserting a `ReturnFlow` witness in the chain, plus the suppression positive (`safe=f(user)`, `f` sanitizes ⇒ `Sanitized` with bypass re-walk)**;  NEGATIVES — NameOnly callee (no edge); multi-Exact callee (no edge + counter); non-simple LHS (skip + counter); Go multi-value with arity mismatch (skip); recursive/self-call (no infinite descent, boundary honored); **mixed modeled/skipped returns ⇒ suppression VOID, shortcut retained (r3-W1 Go case); nested-call unbound Use ⇒ shortcut retained; `return user + "x"` ⇒ ReturnValue + ReturnInput flow; Python keyword-label `s=other` ⇒ NO ReturnInput (r3-W2);** return-of-literal (edge exists, taint does not propagate through it to unrelated vars); sanitizer-on-return-path still sanitizes (reasoning/sanitizer_walk integration).
2. Same-base control (r1-S4 — byte-compat is NOT "by construction" once synthetic nodes enter the unified graph: full_flow enumerates unified nodes_at, full_flow.rs:86-140; `dfg_forward_reachable` traverses the CPG, query.rs:650-715): PER-CONSUMER byte gates — `--format review` (cold AND cache-hit runs), full_flow, **left_flow (direct non-compact control — r2-S8)**, chop, thin_slice outputs all byte-identical on fixtures + a real corpus diff (**kimi-W2: `taint_reaches` is EXCLUDED from the byte set — its verdict changes are the intended feature, pinned by gate-1 positives; its Evidence schema is additive-only; there is no other 'reachability' output surface**); cold vs cache-hit indexing of the synthetic nodes byte-agrees (kimi-S7: the loader rebuilds indexes per-variant, cpg_cache.rs:545-576 — named here, proven by the parity battery).
3. 5-corpus `call-stats`: **byte-identical after removing the single new `return_flow` counter sub-object, whose values are pinned per corpus (r2-W4 — an intentional, declared schema delta; resolution counters untouched)**.
4. Suite + `cargo build --release` + tier-a `--matrix-only` AND `--quick` (r1-S7: the repo rule for changes touching CPG construction); fmt; cache round-trip + four-path parity battery for the CPG bump; skipped-counter custody: counters retained in call-stats output (exported, not debug-only).
5. Measured brief in the PR: per-corpus `ReturnFlow` edge counts + skipped-counter histogram (the follow-up decisions — multi-Exact fan-in, field-sensitive returns, default-ON — get sized by these numbers).

## 4. Risks
- R1: synthetic return locations leaking into non-taint outputs — protected by per-consumer kind filtering (kimi-S4: DataFlow-only traversals, Variable-Use-only enumerations), PROVEN by gate 2, never claimed structural. Build-time artifacts are `CpgEdge::{ReturnFlow,ReturnInput}`; `Relation` twins are trace-witness metadata only.
- R2: multi-value/destructuring corner explosion — bounded by the simple-LHS + arity-match rule; counters expose the residual.
- R3: trace cycle safety in the ascent direction — the existing boundary doctrine + fixture.
