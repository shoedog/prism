## Frozen plan and contract

Extend only the opt-in configured observer. Schema /0→/1 and producer0.1→0.2;
old packets reject before project access. No Prism cache-version change. Every
packet/validator result still authorizes_runtime_edge=false and class_authority=false.

For each existing direct annotated function observation, record a bounded chain
from its annotation through explicit named/default import and named re-export
aliases, namespace-qualified references, and named TypeAliasDeclaration bodies
that are type references. Use the compiler's immediate alias operation, never
present its collapsed final symbol as a complete chain. Retain per-hop reference,
alias declaration/target, declaration, type-parameter and type-argument anchors.
All coordinates remain in each node's defining source; no rebinding in the consumer.

Inline function/callable-literal annotations and non-inherited singleton callable
interfaces may be terminals. A terminal is declaration provenance, NOT class or
runtime ownership. Generic arguments and binders are syntax evidence only: no
arbitrary substitution, mapped/conditional/intersection/union type evaluation or
proof of an instantiated class. Explicit implementation parameter annotations
remain explicit and independent of the outer chain.

Conservatively stop on star exports in a consulted module, unknown/multiple
declarations, import-equals/export-assignment paths in the primary callable chain,
inheritance, unsupported types/declarations, cycles or step exhaustion. Namespace
qualifiers may end at source modules/namespace declarations, including React's
export-equals namespace, but confer no authority from their spelling. Record
partial evidence with an unproven reason; never jump to a global-name fallback.
Top-level program closure and per-chain traversal status are separate: traced
does not certify missing dependency/augmentation closure or unique runtime targets.

One step budget per observation includes reference, alias and qualifier visits.
The new module's bytes join the producer digest. Pre-I/O schema/anchor checks cover
all added nested anchors; full recomputation covers transitions and tampering.
