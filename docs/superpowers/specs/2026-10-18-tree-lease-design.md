**Census rule and timing:** S1 first introduces a private frozen session/file facade with **no `ParsedFile`, Tree, dereference-to-eager, or optional resident-tree accessor**. In a controlled compile-only migration probe, switch each built-in MCP entry boundary (`tools*.rs`, navigation, reasoning, freshness, reporting, owner selection) to that type. Save the complete compile-error population, repeating enumeration until all dependent sites are exposed, before writing N-family manifests. Classify each site as metadata, leased operation, construction-only or explicitly eager API. No compiler run occurs in this design turn.

A slice resolves its assigned errors through shared internal cores and eager public wrappers; inactive fixture adapters let accepted parents compile without activating eviction. Compiler checks catch owned-result calls and inferred holders that the old text census missed. They do not prove absence of hidden construction or clone/stash: additionally audit every reachable parser/Tree constructor, clone and callback/function-pointer edge. An eager-map reconstruction adapter or “tree absent means no data” branch is forbidden. Activation requires every entry point compiled against frozen storage, every census row disposed, and actual ownership witnesses; no assertion of completeness from grep alone.

## 3. Frozen ownership, execution and API contract

| Object / transition | Contract |
|---|---|
| Frozen generation | Retain source text, path/hash, language/grammar identity, line/function tables and parse-quality facts; accepted/skipped set, manifests/resolver presence/absence/coverage, scope inputs/type-db identity, freshness/fingerprint; whole-repo CPG/CG/DFG, type registry/live types and navigation indexes. Source/graphs belong to one immutable Arc generation. No query reads current disk. |
| Publication conversion | Consume the eager build result after facts are built; move owned source/tables/metadata rather than keep a `LoadedRepo` mirror. Drop every Tree and node-bearing builder/cache before publish. Temporary `ParsedFile` framework/call-argument/export caches do not survive implicitly; any retained owned fact must be explicitly accounted. The refreshed serving index has exactly this frozen ownership, including unchanged files, not just changed-file eviction. |
| Cache-hit load | Parse each accepted file **once as today**, reuse the same resident Trees for provider/live-type work, then freeze/drop. Existing auxiliary loader parses remain unchanged. No separate lease passes for providers or live types. Preserve cache versions/acceptance; ownership alone requires no format bump. Gate total load including conversion/destruction at max(5%,100 ms). |
| Tree owner / callback | A private non-cloneable job guard owns one temporary ParsedFile/Tree and parser resources. A higher-ranked closure borrows it; sealed tree-free owned results only. Nodes, cursors, iterators, framework CallSites, node-bearing caches and raw `node.id` cannot escape. Audit Tree/ParsedFile cloning and side-effect stashing: HRTB alone cannot prevent owned clones. Compile-fail escapes plus retention witnesses are required. |
| Helper lifetime | Lease-local reference-search, JS-binding and call-argument caches die before their Tree. Reconstruction identities outside a lease use generation+path+hash+grammar+kind/range, never raw node.id. Preserve public eager helpers through shared cores and private adapters, including Q's validator seam. |
| Per-request work | At most one full-file reparse per distinct file/request across seeds, warnings, all witness pairs and sanitizer advice. Stage sufficient owned facts on first visit, then join/filter against graph traces; do not merely memoize individual helper answers that force a later revisit. No tree memo/LRU/TTL. Source-only and name-prefilter operations parse zero files. Count owned staging bytes; inability to meet this schedule parks that family for bounded redesign. |
| Executor / global K | One process-wide **K-thread dedicated lease executor**, each worker with **256 MiB virtual stack**, matching `build_pool.rs:1–29` recursion rationale. Parse **and callback/drop** run there, never on a daemon/stdio request thread. FIFO queued jobs own no Trees; each worker runs at most one file job, so at most K Trees with Q eliminating auxiliary overlap. No per-language/provider/generation pool multiplication. K=0 is invalid. |
| Scheduling | Worker occupancy is the admission slot: acquire/start only on the executing worker, before parser allocation. Release after all tree/helper destruction. No nested lease, executor reentry, `build_pool::install`, Rayon join/scope or child work waiting under a lease. Dedicated workers do not wait on provider/control operations. The existing eager build pool is separate and outside K. |
| Lock order | Preserve provider read locks around queries and write locks around refresh (`daemon/coordinator.rs:307,329`; `connection.rs:158`). Provider/session → executor queue mutex; drop queue mutex before parse/callback/waiting for results. Publication remains provider → control (`coordinator.rs:349`), after eager tree destruction and with no queue lock. No control → provider/queue edge; lease workers never acquire/reenter provider or control locks. This is not D13 off-lock refresh. |
| OnceLock rule | Never acquire/submit/wait for a lease inside a **shared** OnceLock initializer; never initialize or wait on such a OnceLock while holding a lease. Resolve shared graph-only call edges outside jobs. Private temporary ParsedFile OnceLocks may initialize inside their owning job if they neither acquire a lease nor create another Tree. No snapshot OnceLock may retain node-bearing helpers. |
| Failures / cancellation | FIFO removes explicitly canceled queued jobs (head or middle) and later jobs progress. Use only cancellation sources actually wired by the transport; if synchronous dispatch has no cancellation notification, disconnect is not promised to cancel work. Running parse stays counted until it returns/unwinds, even if response delivery fails. Callback errors/panic drop helpers/Tree/parser before worker release; preserve fatal-daemon panic policy. Abort promises no Drop. |
| Byte bound | K bounds Tree count, not AST bytes or committed stack pages. Source limit 2 MiB (`repo_loader.rs:13`) is not an AST expansion bound. Record largest file, active Tree bytes, stack/allocator footprint and queue costs; reduce K or park on failing gates. No new file rejection or byte-weighted admission in this first design. |
| Public surface | Preserve `ParsedFile.tree` and node-returning/taking methods, `LoadedRepo.files`, `NavigationSession.repo/index`, `CpgContext.files`, `SessionProvider::session` and `ToolContext`. Never synthesize an eager view for a private query. External struct-literal and borrow-compilation fixtures protect compatibility. |
| Nonbreaking selector | `ServerConfig` (`mcp/session.rs:35`) has exhaustive public fields: **add no field**. Add separate public, doc-hidden leased entry points for stdio/daemon/memreport, taking existing config plus a separate runtime-options argument. Existing `run`, `run_daemon`, owner and report entry points remain eager with unchanged signatures/defaults. |
| Binary selection | A binary-local `--tree-mode=eager\|leased` selector chooses the additive entry points; leased mode/K is off through preparatory slices, default only at T3d after gates. Same binary selects eager for byte controls. Daemon identity/launch handoff includes mode and K, preventing attachment to a server with another mode; it must not change repository cache identity. Owner mode remains eager; an explicit owner+leased combination reports an incompatibility instead of silently falling back. |
