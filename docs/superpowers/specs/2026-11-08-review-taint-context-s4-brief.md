Byte accounting decision, made before implementation: original SPEC.md section2.3 defines8MiB of total context source, not cumulative I/O. Cap accepted/staged context-source bytes across rounds, excluding baseline files. Each targeted read is bounded by min(2MiB, remaining staged capacity) plus one overflow sentinel. Count all bytes actually returned, including sentinels, rejected UTF8/parse reads and abandoned-round work, in monotonic attempted_read_bytes. Rejected files do not consume retained-source capacity; only completed bundle bytes appear as published admitted_bytes. Rollback never refunds attempted work or elapsed time. Attempted source I/O may exceed8MiB, and inherited advisory Go hint reads are separately uncapped; neither is represented as an8MiB cumulative-I/O guarantee.
