## Contract

Observe fixed Git archives of pinned Excalidraw and the owner-authorized private
frontend repository. No installs, lifecycle scripts, worktree mutation or remote
private source publication. The native example loads the snapshot through the
existing loader, then builds an unenriched CPG from only JavaScript/TypeScript/TSX
loaded files. Other loaded languages are outside this declared graph population;
loader skip records remain observations of the loader, not a recursive asset census.

Keep four quantities distinct: parameter syntax entries, occurrence API tokens,
actual token-matching DFG/CPG definitions, and actual CPG Use-to-Def DataFlow
endpoints. `all_functions` is the production inventory, not every raw callable
AST node. Null language-level owner names are retained, not silently dropped.
Recovery can produce a retained parameter plus a sibling ERROR; syntax entries
are not proof of a valid parameter list. Preserve whole-list recovery status.

Parameter forms partition syntax entries (required/optional/default identifiers,
patterns/rest, properties/decorators/this, single arrows, recovery/other). These
are observations, not new supported resolver syntax. Flow counts preserve exact
source endpoints and confidence bytes; matching a slot token does not establish
compiler correctness or receiver authority. Body-definition fallback endpoints
must not count as parameter-token flow.

The comparator refuses schema/authority changes, input manifests/skips or static
function/parameter/slot changes, duplicates and malformed coordinates. Measured
occurrences may change. Compare flow multisets, not only counts or sets. Publish
aggregates only for the private corpus; retain raw paths/names and hashes locally.

## Verification and decision

Native classification RED-first; exact token/field-only/duplicate controls and a
body-fallback fixture. Comparator mutation tests, including empty-to-populated
occurrences, changed static inputs, duplicate IDs and multiplicity. Run both
artifacts on identical roots; source-read selected public sites to distinguish
real regressions from inventory barriers. Full Rust configurations, Python,
observer/helper/authority suites and all examples before closeout. Tier-A is not
triggered by standalone example/docs tooling; production construction/navigation
is unchanged. Review cap2; park open-class findings rather than expanding scope.

Next recommendation follows measured value. A demonstrated wrong endpoint takes
priority over optional/default recall expansion; this slice documents/proves it
without silently modifying production policy.
