## Dispatcher interactions

Cheap equality, disjointness or priority can settle the outcome. Unknown installation costs full and binding on the potentially colliding keys. Proved co-installation costs only the undecidable binding. A proved rejection records failed_roots. Test an unaffected later key under uncertainty and a healthy independently entered root beside a proved failure.

The middle column is the closed list of implicit events for the supported adapters. Include events in their native setup order when enabled. A known disable suppresses the claim. Unknown enablement, scope or name reserves the keys it could affect. Internal claims create no synthetic user registration, mount, callback or declared schema method. Withhold binding on overlap. If an internal write could also prevent installation, apply the same full-path rule. A proof of disjointness, order or native priority can clear the affected key.
