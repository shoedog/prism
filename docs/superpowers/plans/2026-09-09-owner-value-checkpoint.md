# Bounded executable-owner value checkpoint

Owner approved the recommendation after PR298 merged. Base: `0807d7de`.
Two self-review rounds maximum; no delegates. This is measurement/documentation,
not a production change or an accuracy baseline.

## Contract and fixed populations

- Exercise the shipped release CLI/MCP with paired compiler/config selection and
  no cache. Use the existing pinned TypeScript 5.9.3; no install or project scripts.
- Real roots: the previously approved, installed public Excalidraw copy and the
  team's current frontend checkout. Read only. Preserve source/control
  hashes and Git status; private paths, source and raw outputs stay local.
- Synthetic controls: every case in the committed executable-owner fixture corpus,
  without editing real repositories or reducing their indexed input sets.
- Separate repository acquisition refusal from an acquired session with no new
  edge. A refused Program gives no receiver-recall denominator. Synthetic success
  is not evidence of practical real-repository recall.
- Retain raw stdout/stderr, input selection, binary/compiler identities and elapsed
  wall times. CLI samples include process startup and query; MCP startup and each
  sequential call are separate. Small warm-filesystem samples are descriptive,
  not p95 estimates or isolated compiler/CPU measurements.
- Capture actual default/owner target evidence. Nonzero status alone does not
  classify a refusal; parse its category or mark the probe inconclusive.
- No closure expansion, react-scripts resolution, React.FC, portable packaging,
  mixed-language/lazy activation, incremental reuse or dependency installation.

## Procedure and stops

1. Verify merged base, clean worktree, source identities and pinned compiler.
2. Build release CLI/MCP; characterize both real roots on the public activation
   path. Three repeated CLI acquisitions each; one eager MCP startup each.
3. Run all committed synthetic controls on ordinary and opted-in CLI, inspect
   target identity/provenance, and time repeated positive acquisition plus five
   sequential MCP calls. Keep existing-route Exact edges separate from owner gain.
4. Source-back observed refusal gates; do not bypass an earlier gate to claim
   later predicates ran. Review denominators, privacy, timing and source custody.
5. Publish the bounded readout, aggregate receipt and handoff. Preserve raw local
   evidence in an archive. No production source/tests changed: full implementation
   suites and Tier-A are not triggered; report only fresh measurement checks.

Stop on source mutation, missing required assets needing installation, unexpected
process behavior, authority expansion or open-class findings at the review cap.
Per process timeout is 90 seconds, output cap 32 MiB. No retries to relax barriers.

  not an isolated compiler profile or production throughput estimate.
