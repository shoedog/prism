# Documentation Archive

The archive retains review transcripts, provenance records, and superseded
planning material for auditability. Archived docs are not current implementation
direction unless an active feature doc links to them explicitly.

| Archive area | Contents |
|--------------|----------|
| `analysis/` | Historical analyses retained for context. |
| `plans/` | Superseded or historical plans, backlog notes, and handoffs. |
| `review-artifacts/prism-query-layer/` | Query-layer spec reviews, plan reviews, code reviews, cleanroom/provenance records, and superseded roadmap material. |
| `operations/` | Historical operational incident notes. |
