**REFINED REVIEW**

1. **BLOCKER - §2 ReceiverCtx seam is under-specified.** Current call extraction passes only qualifier text plus call span to `recover_receiver`; type assertions are rejected by the simple-identifier gate (`src/call_graph.rs:1384-1411`). The classifier needs the call node or selector receiver node, not just `qualifier`, and both full `build` and `build_direct_subset` paths must use the same classifier.

2. **BLOCKER - §2 “legacy extracted verbatim” is not a clean move.** Legacy recovery depends on private `ParsedFile` helpers: `find_parameters_node`, `walk_receiver_bindings`, `constructor_type`, `simple_binding_text`, Go parameter binding (`src/ast.rs:3783-3979`). Specify whether these helpers move, become public, or the classifier remains AST-adjacent.

3. **BLOCKER - §8 manifest denominator is undefined.** “Every interface-method call-site, resolved or not” (`docs/...receiver-expansion-design.md:170-176`) has no inclusion predicate for unrecovered receivers. Define whether this means explicit interface-typed/asserted forms only, or any selector whose method name appears on a known interface.

4. **BLOCKER - §8 manifest identity should not be `file:line`.** Current `CallSite` has byte spans and orders by them (`src/call_graph.rs:27-31`, `1347-1357`), while Tier-A fingerprints are line-keyed (`eval/tier_a/cli.py:96-122`). Use `file:start_byte:end_byte` as the primary manifest key, with `file:line` as display.

5. **BLOCKER - §3 / §12 concrete asserted receivers are contradictory.** §3 says asserted type may be “interface name (or concrete)” (`:112-113`), but §12 says non-interface asserted receivers are unaffected (`:246-248`). Decide: recover only interface assertions, or also resolve concrete asserted receivers and define their `ResolutionKind`.

6. **MAJOR - §3 grammar should be pinned now.** Replace “verify at plan time” with the actual 0.23.4 shape: `call_expression.function = selector_expression`, selector `operand = type_assertion_expression`, assertion `type = _type`. Include `pkg.Module`, `*T`, parenthesized type, and comma-ok non-receiver exclusions.

7. **MAJOR - §4 interface-local API and syntax need tightening.** `GoTypeProvider.interfaces` is private; either expose `is_interface_type`, pass a precomputed set, or state that `TypeProvider::resolve_type(...).kind == Interface` is the predicate. Also remove “annotated short-var”: Go has `var r Runner = f()`, not annotated `r :=`.

8. **MAJOR - §4 local binding coverage is incomplete.** Specify `var r Runner`, `var r Runner = f()`, `var r, s Runner`, `var (...)`, package-level vars, reassignments, and shadowing. Current recovery uses “bindings at/before call; >1 binding bails” (`src/ast.rs:326-379`, `3828-3887`); either reuse that rule or replace it explicitly.

9. **MAJOR - §8 precision report lacks a computation rule.** Define whether “interface-dispatch-attributable FPs in ExactOnly” uses raw prism-only sites, corrected adjudication, pending records, or excludes `ambiguous` / `oracle_artifact`. Add JSON fields by corpus, direction, receiver class, raw FP, corrected FP, pending, ambiguous.

10. **MAJOR - §2 / §13 fallback surface conflicts.** The spec both defaults to `expanded` and leaves default/config open. Pick the runtime surface now: config enum plus per-form booleans is the least ambiguous, with tests for `legacy`, `type_assertion_only`, `interface_local_only`, and full `expanded`.

11. **MAJOR - §10 / §11 Slice A should be mandatory pre-PR.** The seam refactor is risky enough to land independently with byte-identical legacy parity (`docs/...receiver-expansion-design.md:203-214`, `234-237`). Treat PR-1 as the engine dependency, but make Slice A the implementation prerequisite for new forms.

12. **MINOR - §5 / §8 `SliceElem` is ambiguous.** If classifier stub returns `None` (`:139-145`), `ReceiverRecovery::SliceElem` will not appear on call sites, yet §8 wants manifest stratification by `SliceElem` (`:173-176`).
