## Review findings and discriminators

1. WRONG (documentation, corrected): predecessor spec said neither TS type-only
   nor Python relative imports is a runtime binding. Python relative imports do
   bind runtime values; only TS type-only imports are erased. The implementation
   already distinguished them; no resolver repair was needed for this wording.
2. WRONG (inherited Rust recall, outside this Python/JS repair slice): the real
   fully qualified call `prism::navigation::module_graph::module_deps` at
   `src/main.rs:183` is absent from both binaries' served callers. Both raw-site
   records are byte-identical, with `UnknownName` and zero targets: this is not a
   served-list cap. The same-source control has the same omission, so #240 did not
   introduce it. Queue a separate Rust qualified-path repair with a minimized
   binary-to-library crate fixture; do not widen this slice or relabel it an
   oracle artifact. It remains unfixed here.
3. SMELL (inherited evidence label): `constructor_local` also labels Python
   annotated locals. Black's `g.dump` initially looked like evidence borrowed from
   the other branch's constructor. Discriminator: remove that branch in a bounded
   fixture; both old/new binaries still emit the same annotation-backed Exact edge.
   Source `src/ast.rs` explicitly maps the assignment's `type` field to that enum.
   This rules out branch borrowing for this site, not arbitrary flow defects.
   Black's factory returns PgenGrammar, whose class body is `pass` and whose dump
   is inherited from Grammar; the observed target is consistent with the source.
   No runtime-soundness claim for arbitrary annotations is made.
