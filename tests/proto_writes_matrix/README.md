Each file in `cases/` exports one utility for the prototype-write analyzer. `rows.jsonl` records the target write line, the argument template, the names derived from that argument, and the expected analyzer result. `call.args` uses zero-based argument positions, and an explicit `call.control` supplies `segments`, `value`, and an `expect` expression over `root` and `ret`. The separate runner expands its input families, checks the benign control, and measures changes to shared prototypes in contained processes. Each row starts with `truth` set to `pending` and takes its final label from the runner output. `sink_rows.md` contains source-only fixtures for the review taint sink.

`truth` is judged over the design's four root kinds (plain, null-prototype, class instance, array); a row that also lists the extended roots `object_ctor` (the `Object` constructor itself) and `global_this` carries a second label `truth_extended` that includes them. Rules are tested against `truth`; `truth_extended` is a disclosed neighbour, not a gate. `truth.jsonl` is frozen for stage D at 326 rows (stage E was closed by the controller); an added family, root or row relabels rows and `truth/check.sh` shows the drift.

Rows `t3-001` to `t3-056` are the pairs the stage D draft listed as still needed (the shape and its neighbouring control). Rows `t2-001` to `t2-178` come from three enumeration tiers (terra 4 rounds, sol 3, astra 2; the declared caps were reached with the tiers still adding variants of the same classes, not new classes). Some use a small exported wrapper that unpacks the runner's path array into the function's own parameters; the row's `class` text says so. Proposals in the lane ledger's list that no enumerator emitted are not rows.

Row fields beyond the first batch: `extra_payloads` (a list of `{id, segments}`: segment lists that name something only that row's function has, such as an application key, a reversed order or an encoded name; run like a family, same containment) and `scope_note` (the row writes a shared base beyond the built-in prototypes, an application-owned or user-class object: `truth: safe` then means only that no built-in prototype changed, and the runner cannot judge the row; stage D treats these rows as out of scope or accepted loss, never as evidence that a rule should stay silent). `attacker_names` lists the names the row's text derives from the attacker argument; a name may appear off the write line (a key or cursor variable bound earlier), which is the convention of the first 92 rows too.

This directory lives outside `tests/fixtures/` on purpose: a repository test indexes every JavaScript fixture under `tests/fixtures/` and its run time grows with their number (it timed out in CI with the matrix there).
