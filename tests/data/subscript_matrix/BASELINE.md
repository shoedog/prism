## Production Exact-only search

The test crate can invoke the production trace and can exclude node pairs.
Those exclusions also remove other transitions between the same endpoints.
The walker internally deduplicates by node for each root and keeps only the
first depth at that node. PLAN T requires a label-specific enqueue filter
and separate visits by traversal context, including depth. The test crate
cannot supply either. The Q02 alternate and clean-return fixtures are
available for later measurement, and the legacy draft route pins retain
their existing graph checks.
